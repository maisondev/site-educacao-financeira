Exemplos para testar

Experimente estes cenários:

  • Cenário conservador: R$ 1.000 inicial + R$ 100/mês à 0.5% = 60 meses
  • Cenário moderado: R$ 2.000 inicial + R$ 300/mês à 0.8% = 120 meses (10 anos)
  • Cenário agressivo: R$ 5.000 inicial + R$ 500/mês à 1.2% = 240 meses (20 anos)

Dicas de interpretação

  • Valor final — é o total que você terá ao final do período
  • Total aportado — é todo o dinheiro que você mesmo colocou (valor inicial + aportes mensais)
  • Ganho com juros — é o dinheiro que o mercado rendeu para você (é o lucro livre, você não trabalhou para conseguir)

Quanto maior o período e a taxa de juros, mais exponencial é o crescimento! Este é o poder dos juros compostos.
